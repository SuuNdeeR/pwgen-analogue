# Password Generator

Консольная утилита для генерации случайных паролей — упрощённый аналог
[pwgen](https://linux.die.net/man/1/pwgen) для Unix-систем.

Курсовой проект по предмету «Технология разработки программного обеспечения».  
Команда: Ступин Егор, Заруднев Андрей, Бубенин Виктор — ИВ-521.

---

## Требования

- ОС: Linux (требуется `/dev/urandom` для флага `-s`)
- Компилятор: `gcc` с поддержкой C11
- Утилиты: `make`, `clang-format`

---

## Сборка

```bash
git clone https://github.com/SuuNdeeR/pwgen-analogue
cd pwgen-analogue
make
```

Бинарник появится в `bin/pwgen`.

---

## Использование

```
./bin/pwgen [ОПЦИИ] [ДЛИНА [КОЛИЧЕСТВО]]
```

**Позиционные аргументы:**

| Аргумент     | По умолчанию | Диапазон  | Описание                        |
|--------------|--------------|-----------|---------------------------------|
| `ДЛИНА`      | 8            | 4 – 256   | Длина генерируемого пароля      |
| `КОЛИЧЕСТВО` | 1            | 1 – 10000 | Количество генерируемых паролей |

**Флаги:**

| Флаг | Длинный           | Описание                                              |
|------|-------------------|-------------------------------------------------------|
| `-c` | `--capitalize`    | Включить заглавные буквы                              |
| `-A` | `--no-capitalize` | Не включать заглавные буквы                           |
| `-n` | `--numerals`      | Включить цифры                                        |
| `-0` | `--no-numerals`   | Не включать цифры                                     |
| `-y` | `--symbols`       | Включить специальные символы (`!@#$%^&*...`)          |
| `-s` | `--secure`        | Безопасная генерация через `/dev/urandom`             |
| `-B` | `--no-ambiguous`  | Исключить неоднозначные символы (`l`,`1`,`O`,`0`,`I`) |
| `-h` | `--help`          | Вывод справки                                         |
|      | `--version`       | Вывод версии программы                                |

По умолчанию включены только строчные латинские буквы (`a-z`).

При конфликте флагов (`-c` и `-A`, `-n` и `-0`) приоритет имеет последний
указанный. Например, `./bin/pwgen -c -A` равносильно `./bin/pwgen -A`.

## Примеры

```bash
# 1 пароль длиной 8 символов (по умолчанию)
./bin/pwgen

# 5 паролей длиной 16 символов с заглавными и цифрами
./bin/pwgen -cn 16 5

# Безопасный пароль из 20 символов со спецсимволами
./bin/pwgen -sy 20

# Пароль без неоднозначных символов (удобно для распечатки)
./bin/pwgen -B 12

# Сохранение пароля в переменную (использование в скриптах)
PASSWORD=$(./bin/pwgen -s 24)
echo "Сгенерирован пароль: $PASSWORD"
```

---

## Коды возврата

| Код | Значение                                                                      |
|-----|-------------------------------------------------------------------------------|
| `0` | Успешное выполнение                                                           |
| `1` | Ошибка аргументов (неверный флаг, недопустимое значение длины или количества) |
| `2` | Ошибка выполнения (например, недоступен `/dev/urandom` при флаге `-s`)        |
